# Cloud Docs

Comprehensive cloud services documentation — AWS, Azure, GCP, Oracle — with insights, perfect use-cases, and local emulator setup.

## Philosophy

- **Use-case journey first**: learn services in real context, not alphabetical lists.
- **Local-first**: each journey runs on your laptop via emulator ([floci.io](https://floci.io) for AWS).
- **Cross-provider**: every concept maps to all providers — switching cloud isn't starting over.
- **Bilingual**: Bahasa Indonesia by default, English mirror.

## Where to start

- New to cloud? → [Foundation](/en/foundation)
- Want to build something? → [Use-Case Journeys](/en/journeys)
- Looking for a specific service? → [Service Reference](/en/services)
- Set up local emulator? → [Tools & Emulator](/en/tools)

## Status

Project in active development. Early phase focuses on AWS (J1-J12). Azure, GCP, Oracle to follow.
