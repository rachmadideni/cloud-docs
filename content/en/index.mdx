## Philosophy

- **Use-case journey first**: learn services in real context, not alphabetical lists.
- **Local-first**: each journey runs on your laptop via emulator (floci for AWS, `supabase start` for Supabase).
- **Cross-provider**: every concept maps to other providers, switching cloud isn't starting over.
- **Bilingual**: Bahasa Indonesia by default, English mirror.

## Status

Project in active development. Early phase focuses on AWS (J1-J12 done, 30+ service reference pages). Supabase is a skeleton. Azure, GCP, Oracle to follow.
