# AWS

Dokumentasi AWS terbungkus journey use-case nyata, plus deep page per service. Local-first lewat [floci.io](https://floci.io) emulator.

## Mulai dari mana?

- Baru kenal cloud / AWS? → [Fondasi](/id/aws/foundation)
- Mau bikin sesuatu konkret? → [Use-Case Journey](/id/aws/journeys)
- Cari service spesifik? → [Service Reference](/id/aws/services)
- Setup emulator + tooling? → [Tools & Emulator](/id/aws/tools)

## Service Reference

30+ service deep page. Tiap halaman ikut template: TL;DR, analogi, perfect use-case, anti use-case, pricing mental model, local emulator status, hello-world, gotcha, cross-provider.

Lihat [Service Reference](/id/aws/services) untuk daftar lengkap.

## Local Emulator

Default pakai [floci.io](https://floci.io): single endpoint `localhost:4566`, 45 service AWS, MIT, free total. Coverage gap (CloudFront, X-Ray, Rekognition, GuardDuty, Bedrock) ada fallback di [Tools & Emulator](/id/aws/tools).
