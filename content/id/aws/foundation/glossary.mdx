# Glossary

Istilah cloud dan AWS yang sering muncul di docs ini. Diurutkan alphabet. Definisi singkat, dengan link ke halaman lebih dalam kalau ada.

## A

- **ACM** (AWS Certificate Manager): service untuk request dan kelola sertifikat SSL/TLS gratis untuk domain kamu.
- **ALB** (Application Load Balancer): load balancer layer 7 (HTTP/HTTPS), routing berdasarkan path atau header.
- **ARN** (Amazon Resource Name): identitas unik resource AWS. Format `arn:aws:<service>:<region>:<account>:<resource>`.
- **AssumeRole**: aksi `sts:AssumeRole` untuk principal mendapat credential temporary dengan permission dari role.
- **Auto Scaling**: feature yang otomatis tambah/kurangi jumlah instance berdasarkan metric (CPU, traffic).
- **AZ** (Availability Zone): data center independen di dalam region. Lihat [Region & AZ](/id/aws/foundation/region).

## B

- **Bucket**: container untuk object di S3. Nama unik global di seluruh dunia.
- **Backup**: copy data untuk disaster recovery. AWS Backup adalah service terpusat untuk schedule.

## C

- **CDN** (Content Delivery Network): cache file di edge location dekat user. AWS punya CloudFront.
- **CloudFormation**: Infrastructure-as-Code AWS native. Template YAML/JSON definisikan resource.
- **CloudFront**: CDN dengan 400+ edge location global.
- **CloudWatch**: service untuk metrics, logs, alarms.
- **Cold start**: delay tambahan saat Lambda function pertama kali invoke setelah idle, 100-500 ms untuk Node.
- **Cognito**: managed user authentication. User pool (login), identity pool (federated identity).
- **Cross-AZ**: traffic antar AZ di region yang sama. Kena charge $0.01/GB tiap arah.
- **Cross-region**: traffic antar region. Kena charge $0.02/GB.

## D

- **Data residency**: regulasi bahwa data tetap di geographic boundary tertentu. Indonesia: PP 71/2019.
- **DNS** (Domain Name System): translate domain ke IP. AWS punya Route53.
- **DynamoDB**: NoSQL key-value managed. Sub-10 ms latency, billed per-request atau provisioned.

## E

- **EBS** (Elastic Block Store): block storage untuk EC2. Volume terikat ke AZ.
- **EC2** (Elastic Compute Cloud): virtual machine. Bayar per detik instance running.
- **ECR** (Elastic Container Registry): Docker registry private AWS.
- **ECS** (Elastic Container Service): orchestration container, alternative dari Kubernetes.
- **Edge location**: data center kecil tempat CloudFront cache file dekat user.
- **Egress**: traffic keluar dari AWS ke internet. $0.09/GB di kebanyakan region.
- **EKS** (Elastic Kubernetes Service): managed Kubernetes control plane.
- **EventBridge**: event bus serverless untuk routing event antar service.

## F

- **Fargate**: serverless compute untuk ECS/EKS. Tidak perlu manage EC2.
- **Floci**: emulator AWS lokal, default tool untuk semua journey di docs ini. Lihat [Tools](/id/aws/tools/floci).
- **Free tier**: paket gratis AWS. 12-bulan (expire) atau always-free (permanen).

## G

- **Glacier**: tier storage S3 super murah untuk archive. Retrieval butuh menit sampai jam.
- **Glue**: ETL managed AWS. Crawler, catalog, job.
- **GSI** (Global Secondary Index): index alternatif di DynamoDB untuk query field non-primary key.

## H

- **Hosted zone**: container untuk DNS record di Route53. $0.50/bulan per zone.
- **HTTP API**: API Gateway v2, versi lebih simpel dan murah dari REST API v1.

## I

- **IAM** (Identity and Access Management): system otorisasi AWS. Lihat [IAM & Identity](/id/aws/foundation/iam).
- **IMDS** (Instance Metadata Service): endpoint internal EC2 yang serve credential dan metadata instance.
- **Ingress**: traffic masuk ke AWS dari internet. Gratis untuk kebanyakan service.
- **Instance**: virtual machine EC2. Punya type (t3.small, m5.large, dll), AMI, dan AZ.
- **Instance profile**: container untuk IAM role yang attach ke EC2 instance.
- **IRSA** (IAM Roles for Service Accounts): pattern untuk pod K8s di EKS mendapat IAM role.

## J

- **JWT** (JSON Web Token): token format untuk auth. Cognito issue JWT setelah login berhasil.

## K

- **KMS** (Key Management Service): managed encryption key. Sign, verify, encrypt, decrypt.
- **Kinesis**: streaming data service. Data Streams (real-time), Firehose (delivery to S3/Redshift).

## L

- **Lambda**: serverless function. Bayar per request + GB-second execution.
- **Latency**: waktu round-trip request. Diukur dalam ms.
- **Least privilege**: prinsip memberikan permission minimal yang dibutuhkan, bukan lebih.

## M

- **Managed policy**: IAM policy yang bisa di-attach ke banyak principal. AWS-managed (built-in) atau customer-managed.
- **MFA** (Multi-Factor Authentication): autentikasi 2 langkah. Wajib untuk root account.
- **Multi-AZ**: deployment yang resource-nya tersebar di beberapa AZ. Untuk high availability.

## N

- **NAT Gateway**: gateway untuk private subnet akses internet. $0.045/jam plus $0.045/GB processed.
- **NoSQL**: database tanpa schema fixed. DynamoDB adalah NoSQL.

## O

- **On-demand**: pricing model tanpa komitmen, bayar per detik. Default EC2 dan DynamoDB.

## P

- **PartiQL**: SQL-like query language untuk DynamoDB.
- **Pay-as-you-go**: model billing per pemakaian. Default AWS.
- **Policy**: dokumen JSON yang nyatakan permission. Identity-based, resource-based, atau trust policy.
- **Presigned URL**: URL S3 dengan signature, allow temporary public access ke object private.
- **Principal**: entitas yang request action di AWS. User, role, service, atau federated identity.
- **Private subnet**: subnet tanpa route ke internet gateway. Akses internet via NAT Gateway.
- **Provisioned**: pricing model dengan kapasitas dialokasi di muka. Lebih murah kalau traffic stabil.
- **Public subnet**: subnet dengan route ke internet gateway.

## Q

- **Quota** (service limit): batas resource per akun per region. Bisa di-request increase.

## R

- **RBAC** (Role-Based Access Control): pattern otorisasi berbasis role. AWS IAM include RBAC.
- **RCU** (Read Capacity Unit): satuan kapasitas read DynamoDB provisioned. 1 RCU = 1 strongly consistent read 4 KB/detik.
- **RDS** (Relational Database Service): managed relational database (Postgres, MySQL, MariaDB, Oracle, SQL Server).
- **Region**: area geografis AWS. Lihat [Region & AZ](/id/aws/foundation/region).
- **Reserved Instance** (RI): komitmen 1 atau 3 tahun untuk EC2, diskon 30-70%.
- **Resource-based policy**: policy yang nempel di resource (S3 bucket policy, Lambda function policy). Jawab "siapa boleh akses ini".
- **Role**: IAM identity tanpa credential permanent, di-assume oleh principal lain.
- **Route53**: DNS service AWS. Hosted zone $0.50/bulan.

## S

- **S3** (Simple Storage Service): object storage. Bucket, object, storage class.
- **SAM** (Serverless Application Model): framework dan CLI dari AWS untuk deploy Lambda + API Gateway dengan template singkat.
- **Savings Plans**: komitmen 1-3 tahun, lebih fleksibel dari RI. Diskon 30-70%.
- **SDK** (Software Development Kit): library untuk akses AWS API dari kode. SDK ada untuk JavaScript, Python, Java, Go, dll.
- **Secret Manager**: managed secret storage dengan rotation otomatis.
- **Security group**: virtual firewall di VPC. Stateful, allow-list rule.
- **Serverless**: kategori service tanpa manage server. Lambda, DynamoDB, S3, API Gateway, EventBridge.
- **Service-linked role**: IAM role yang auto-create oleh AWS service untuk dirinya sendiri.
- **SNS** (Simple Notification Service): pub/sub messaging. Topic + subscriber (SQS, Lambda, HTTP, email).
- **Spot instance**: EC2 dengan diskon 70-90%, bisa di-terminate AWS sewaktu-waktu.
- **SQS** (Simple Queue Service): managed message queue. Standard atau FIFO.
- **SSE** (Server-Sent Events): protokol streaming HTTP satu arah server ke client. Lambda + API Gateway support.
- **SSL/TLS**: protokol encryption untuk HTTPS. ACM issue cert gratis.
- **Step Functions**: state machine serverless untuk orchestrate workflow.
- **STS** (Security Token Service): service untuk issue credential temporary via AssumeRole.
- **Subnet**: subdivisi VPC. Terikat ke satu AZ. Public atau private.

## T

- **Tag**: label key-value yang nempel di resource. Untuk cost attribution dan organization.
- **Throttle**: rate limit. Lambda, API Gateway, DynamoDB punya throttle protect dari traffic spike.
- **Trust policy**: jenis IAM policy khusus role, nyatakan siapa boleh assume role itu.

## U

- **Use case**: konteks aplikatif untuk service. Tiap halaman service di docs ini punya "Perfect use case" dan "Anti use case".
- **User**: IAM identity long-term untuk manusia atau aplikasi external. Hindari user untuk aplikasi di AWS, pakai role.

## V

- **VPC** (Virtual Private Cloud): virtual network terisolasi per region. Berisi subnet, route table, gateway.
- **VPC endpoint**: koneksi private dari VPC ke service AWS, tanpa lewat internet. Gateway endpoint (S3, DynamoDB gratis) atau Interface endpoint (service lain, $0.01/jam).
- **VPN**: virtual private network. Site-to-Site VPN connect on-prem ke VPC.

## W

- **WAF** (Web Application Firewall): firewall layer 7 untuk filter HTTP request. Pasang di CloudFront atau ALB.
- **WCU** (Write Capacity Unit): satuan kapasitas write DynamoDB provisioned. 1 WCU = 1 write 1 KB/detik.

## X

- **X-Ray**: distributed tracing service. Lihat request flow lewat banyak service.

## Z

- **Zone**: lihat AZ.

## Istilah cross-provider

Padanan istilah AWS ke provider lain.

| AWS | Azure | GCP | Oracle |
|---|---|---|---|
| EC2 | Virtual Machine | Compute Engine | Compute |
| S3 | Blob Storage | Cloud Storage | Object Storage |
| DynamoDB | Cosmos DB | Firestore / Bigtable | NoSQL Database |
| RDS | Database for Postgres/MySQL | Cloud SQL | Autonomous Database |
| Lambda | Functions | Cloud Functions / Cloud Run | Functions |
| VPC | Virtual Network | VPC | Virtual Cloud Network |
| IAM | Entra ID + RBAC | Cloud IAM | OCI IAM |
| CloudFront | Front Door / CDN | Cloud CDN | OCI CDN |
| Route53 | DNS | Cloud DNS | OCI DNS |
| KMS | Key Vault | Cloud KMS | Vault |
| Region | Region | Region | Region |
| AZ | Availability Zone | Zone | Availability Domain |
