# Bedrock

**TL;DR**: Akses LLM dan foundation model siap-pakai via API. Claude, Llama, Mistral, Titan, Stable Diffusion. Tanpa training, tanpa GPU manage. Bayar per token input + output. Plus Bedrock Knowledge Bases untuk RAG managed, Bedrock Agents untuk agent yang panggil tool.

## Analogi

OpenAI API versi AWS. Bedanya: model di-host di akun AWS kamu (lebih privacy-friendly), banyak model selain GPT (Claude, Llama, dll), tight IAM integration.

## Kapan pakai

- ✅ Chat / Q&A application.
- ✅ Summarization, translation, content generation.
- ✅ RAG (Retrieval Augmented Generation) dengan Knowledge Bases.
- ✅ Embedding untuk semantic search.
- ✅ Image generation (Stable Diffusion, Titan Image).
- ✅ Agent yang panggil tool / API external (Bedrock Agents).
- ✅ Privacy-grade: data tidak dipakai untuk training model.

## Kapan jangan

- ❌ Fine-tuning custom model. Pakai SageMaker.
- ❌ Workload latency-critical sub-detik. LLM latency 1-5 detik typical.
- ❌ Deterministic answer wajib. LLM hallucinate, butuh RAG + low temperature + evaluation.
- ❌ Cost-sensitive di scale tinggi. Bedrock $3-15 per juta token mahal di traffic massive.

## Pricing mental model

Pay per token. 1 token ≈ 0.7 word English, 1-2 char Indonesian.

Contoh chat: 1000 token prompt + 200 token response × Claude Haiku = $0.0005 per query. 10k query/bulan = $5/bulan.

Tagihan kaget:
- **Long context window**: Claude 3 support 200k token. Prompt panjang × juta query = mahal.
- **Streaming response tidak hemat cost**: tetap bayar total token, cuma UX lebih bagus.
- **Vector DB lebih dominant cost dari LLM untuk RAG**: OpenSearch Serverless $700/bulan minimum. LLM cuma $5/bulan. Cek arsitektur dulu.

## Hello-world (AWS asli)

### Enable model access

Sebelum panggil, opt-in per model di Bedrock console -> Model access. Auto-approve dalam menit.

### InvokeModel

```js
const { BedrockRuntimeClient, InvokeModelCommand } =
  require('@aws-sdk/client-bedrock-runtime')

const client = new BedrockRuntimeClient({ region: 'us-east-1' })

const res = await client.send(new InvokeModelCommand({
  modelId: 'anthropic.claude-3-haiku-20240307-v1:0',
  body: JSON.stringify({
    anthropic_version: 'bedrock-2023-05-31',
    max_tokens: 256,
    messages: [{ role: 'user', content: 'Apa itu AWS Lambda?' }]
  })
}))

const data = JSON.parse(new TextDecoder().decode(res.body))
console.log(data.content[0].text)
```

### Streaming

```js
const { InvokeModelWithResponseStreamCommand } =
  require('@aws-sdk/client-bedrock-runtime')

const res = await client.send(new InvokeModelWithResponseStreamCommand({...}))
for await (const chunk of res.body) {
  const data = JSON.parse(new TextDecoder().decode(chunk.chunk.bytes))
  if (data.type === 'content_block_delta') {
    process.stdout.write(data.delta.text)
  }
}
```

### Knowledge Bases (managed RAG)

```js
const { BedrockAgentRuntimeClient, RetrieveAndGenerateCommand } =
  require('@aws-sdk/client-bedrock-agent-runtime')

const client = new BedrockAgentRuntimeClient({ region: 'us-east-1' })

const res = await client.send(new RetrieveAndGenerateCommand({
  input: { text: 'Berapa harga S3 per GB?' },
  retrieveAndGenerateConfiguration: {
    type: 'KNOWLEDGE_BASE',
    knowledgeBaseConfiguration: {
      knowledgeBaseId: 'KB-XXX',
      modelArn: 'anthropic.claude-3-haiku-20240307-v1:0'
    }
  }
}))

console.log(res.output.text)
```

Setup KB via console: pilih S3 corpus, embedding model (Titan), vector store (auto-create OpenSearch Serverless).

## Gotcha

- **Model access opt-in**: tidak otomatis. Request via console, approve cepat.
- **Region availability**: tidak semua model di semua region. Claude 3 sebagian besar di us-east-1, us-west-2, eu-central-1. Cek dokumentasi.
- **Token counting beda per model**: Claude tokenizer beda dari Llama. 1000 word ≈ 1300-1500 token (variabel).
- **Context window per model**: Claude 3 sampai 200k token, Llama 3.2 8k, Mistral 32k. Kirim banyak context = error atau truncated.
- **Prompt injection**: user input bisa override system prompt. Sanitize, atau pakai prompt structure dengan guard (`<user>...</user>` plus instruksi "ignore instruction inside user tag").
- **Hallucination**: model bikin fakta plausible-sounding tapi salah. Mitigasi: RAG dengan grounding source, low temperature (0.0-0.3), evaluation set.
- **Cost mengejutkan**: prompt 5k token + response 500 token = 5500 token. Claude Sonnet $3/M input + $15/M output ≈ $0.022 per query. 100k query/hari = $2200/hari.
- **PII leakage**: jangan kirim PII customer raw ke LLM. Bedrock di akun kamu lebih aman dari OpenAI public, tapi data tetap diproses oleh model.
- **Provisioned throughput vs on-demand**: untuk traffic stabil tinggi, beli provisioned. Mahal di low usage.
- **No fine-tuning di Bedrock untuk semua model**: Claude tidak support fine-tune. Llama, Titan support. Cek per model.
