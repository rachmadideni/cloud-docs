# SageMaker

**TL;DR**: Platform ML end-to-end. Notebook, training job, hyperparameter tuning, deploy endpoint, monitoring. Cocok kalau butuh train model sendiri atau host model custom. Lebih kompleks dari Bedrock yang sudah siap-pakai foundation model.

## Analogi

Workshop kerajinan lengkap untuk ML. Mesin (notebook + cluster training), bahan baku (data dari S3), tempat display (endpoint), QC (model monitoring). Bedrock = beli produk jadi. SageMaker = bikin produk sendiri.

## Kapan pakai

- ✅ Train model custom (classification, regression, time-series, recommendation).
- ✅ Fine-tune foundation model dengan data domain spesifik.
- ✅ Host model custom di endpoint (TensorFlow, PyTorch, ONNX).
- ✅ Hyperparameter tuning otomatis dengan Bayesian search.
- ✅ Production ML dengan model monitoring (drift detection).
- ✅ MLOps pipeline (notebook -> training -> registry -> deploy).
- ✅ Distributed training di multi-GPU.

## Kapan jangan

- ❌ Cuma butuh LLM inference. Pakai Bedrock (jauh lebih simpel).
- ❌ Quick prototype tanpa production deploy. Pakai Colab atau Jupyter lokal.
- ❌ Workload kecil yang fit Lambda. Lambda dengan model di S3 lebih murah dari endpoint persistent.
- ❌ Team tanpa data scientist. SageMaker terminology dan flow rumit.

## Komponen utama

| Komponen | Fungsi |
|---|---|
| **Studio** | IDE web untuk ML (notebook, experiment, debug) |
| **Notebook Instance** | EC2 dengan Jupyter pre-installed |
| **Training Job** | scheduled compute untuk train model |
| **Hyperparameter Tuning** | search best param dengan Bayesian/grid/random |
| **Processing Job** | data preprocessing/postprocessing |
| **Model Registry** | versioned model storage |
| **Endpoint** | persistent endpoint untuk inference |
| **Batch Transform** | inference batch besar (tanpa endpoint) |
| **Serverless Inference** | endpoint scale ke 0 saat tidak dipakai |
| **JumpStart** | template + pre-trained model siap deploy |
| **Pipelines** | MLOps workflow definition |
| **Model Monitor** | drift detection production |
| **Clarify** | bias + explainability analysis |
| **Feature Store** | feature engineering centralized |

## Pricing mental model

| Komponen | Harga (us-east-1) |
|---|---|
| Studio (free tier) | 250 jam ml.t3.medium/bulan |
| Notebook instance | EC2 standard pricing |
| Training job | per-instance per-detik |
| Hyperparameter tuning | per-trial × instance cost |
| Endpoint (real-time) | per-instance per-jam (running 24/7) |
| Serverless Inference | per-invocation + duration |
| Batch Transform | per-instance per-detik |
| Model Monitor | per-job |

Sticker shock paling parah: **endpoint real-time idle**. ml.m5.large endpoint = $0.115/jam = **$83/bulan running terus**, walau zero invocation. Pakai Serverless Inference untuk traffic rendah.

Training job: GPU instance mahal. ml.p4d.24xlarge = $32.77/jam. Job multi-jam = ratusan dolar per run.

## Local emulator

**Floci status**: ❌ gap (training mahal di lokal)

Konseptual only. Untuk experiment ML:
- **Jupyter Notebook lokal**: install Python + scikit-learn / TensorFlow / PyTorch.
- **Colab** (gratis): notebook dengan GPU gratis terbatas.
- **Kaggle Notebooks**: gratis dengan GPU + TPU.

Untuk training serius, pakai SageMaker di AWS asli. Tidak ada substitusi yang fit untuk fitur seperti distributed training, managed endpoint.

## Hello-world (AWS asli)

### JumpStart deploy pre-trained model

```python
from sagemaker.jumpstart.model import JumpStartModel

# Deploy Llama 3 8B
model = JumpStartModel(model_id="meta-textgeneration-llama-3-8b-instruct")
predictor = model.deploy(
    instance_type="ml.g5.2xlarge",
    initial_instance_count=1
)

# Inference
response = predictor.predict({
    "inputs": "Apa itu Kubernetes?",
    "parameters": {"max_new_tokens": 256}
})
print(response)

# Cleanup penting (biar tidak bayar terus)
predictor.delete_endpoint()
```

### Training job custom

```python
from sagemaker.pytorch import PyTorch

estimator = PyTorch(
    entry_point='train.py',  # script PyTorch kamu
    role='arn:aws:iam::xxx:role/SageMakerRole',
    framework_version='2.0',
    py_version='py310',
    instance_count=1,
    instance_type='ml.g4dn.xlarge',
    hyperparameters={'epochs': 10, 'batch-size': 64}
)

estimator.fit({'training': 's3://my-bucket/train-data/'})
```

### Serverless Inference

```python
from sagemaker.serverless import ServerlessInferenceConfig

serverless_config = ServerlessInferenceConfig(
    memory_size_in_mb=2048,
    max_concurrency=5
)

predictor = model.deploy(serverless_inference_config=serverless_config)
```

Scale ke 0 saat tidak dipakai. Cold start beberapa detik. Cocok untuk traffic rendah atau bursty.

## Gotcha

- **Endpoint idle = bayar 24/7**: lupa hapus endpoint = ratusan dolar tagihan diam-diam. Selalu `delete_endpoint()` setelah eksperimen.
- **Notebook instance idle juga charged**: stop notebook setelah selesai. Tidak auto-stop.
- **Training time tidak prediktabel**: tergantung data size, model complexity. Set timeout supaya tidak runaway cost.
- **GPU quota request**: instance GPU (p4d, p5, g5) sering kena default quota 0. Request increase sebelum mulai.
- **Spot training**: pakai spot instance untuk training (70% diskon). Set `use_spot_instances=True` + `max_wait` + `max_run`.
- **Model artifact di S3**: training output (model.tar.gz) di S3. Versioning manual atau pakai Model Registry.
- **Endpoint instance type vs cost**: ml.t2.medium minimum ~$30/bulan. ml.m5.large $83. Right-size berdasarkan latency requirement.
- **Multi-model endpoint**: 1 endpoint host banyak model. Hemat untuk banyak model dengan low traffic per model.
- **JumpStart model size**: foundation model gede (50-300 GB). Storage + transfer ke endpoint butuh waktu deploy 5-15 menit.
- **Studio vs Notebook Instance**: Studio adalah IDE web baru, Notebook Instance legacy. Studio preferred.
