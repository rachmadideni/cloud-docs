# DynamoDB

**TL;DR**: NoSQL key-value managed dengan latency sub-10 ms. Auto-scale, tidak ada server yang harus dipatched. Schema flexible, tidak ada JOIN. Cocok untuk workload high-throughput dengan query pattern jelas dari awal.

## Analogi

Spreadsheet raksasa dengan dua jenis key (partition + optional sort). Bisa miliaran row. Bisa ditarik per key dalam ms. Tapi tidak bisa di-JOIN dengan spreadsheet lain via SQL.

## Kapan pakai

- ✅ Lookup by ID dengan latency rendah konstan (mis. session store, user profile, shopping cart).
- ✅ Workload dengan query pattern stabil (bisa dirancang index dari awal).
- ✅ Counter dan rate limiter (atomic increment dengan UpdateExpression).
- ✅ Time-series data sederhana dengan sort key timestamp.
- ✅ Backend serverless Lambda yang butuh database scale dari 0.
- ✅ Multi-region active-active via Global Tables.
- ✅ Event sourcing dengan DynamoDB Streams.

## Kapan jangan

- ❌ Aplikasi dengan banyak relasi antar entity yang butuh JOIN. Pakai RDS.
- ❌ Query ad-hoc yang tidak diketahui dari awal. Pakai relational DB.
- ❌ Full-text search. Pakai OpenSearch.
- ❌ Reporting dan analytics dengan aggregate SQL kompleks. Pakai Athena di atas S3 atau Redshift.
- ❌ Workload kecil (puluhan request per detik). RDS small instance lebih murah.

## Pricing mental model

Dua mode billing:

### PAY_PER_REQUEST (on-demand)

| Komponen | Harga |
|---|---|
| Write Request Unit (WRU) | $1.25 per 1 juta |
| Read Request Unit (RRU) | $0.25 per 1 juta |
| Storage | $0.25 per GB per bulan |

1 WRU = 1 write 1 KB. 1 RRU = 1 strongly consistent read 4 KB (eventually consistent = 0.5 RRU).

Cocok untuk traffic spiky atau tidak prediktabel. Bayar sesuai pemakaian, tanpa setting capacity.

### PROVISIONED

| Komponen | Harga |
|---|---|
| Write Capacity Unit (WCU) | $0.00065 per WCU per jam |
| Read Capacity Unit (RCU) | $0.00013 per RCU per jam |

1 WCU = 1 write/detik 1 KB sustained. 1 RCU = 1 read/detik 4 KB strongly consistent.

Lebih murah ~7x dari PAY_PER_REQUEST kalau traffic stabil dan terukur. Pakai auto-scaling untuk handle variability.

Komponen lain:
- **Global Tables**: replikasi multi-region, bayar storage di tiap region plus write replication (RWU).
- **Streams**: gratis 4 first 24 jam GetRecord, di luar itu $0.02 per 100k.
- **Backup**: continuous backup $0.20/GB/bulan, on-demand $0.10/GB.

## Local emulator

**Floci status**: ✅ full (termasuk Streams, GSI, TTL)

```bash
awsl dynamodb create-table \
  --table-name Users \
  --attribute-definitions AttributeName=user_id,AttributeType=S \
  --key-schema AttributeName=user_id,KeyType=HASH \
  --billing-mode PAY_PER_REQUEST
```

Alternatif: **DynamoDB Local** (JAR resmi AWS), bisa standalone.

## Hello-world

```js
const { DynamoDBClient } = require('@aws-sdk/client-dynamodb')
const { DynamoDBDocumentClient, PutCommand, GetCommand, QueryCommand } =
  require('@aws-sdk/lib-dynamodb')

const ddb = DynamoDBDocumentClient.from(new DynamoDBClient({
  endpoint: 'http://localhost:4566',
  region: 'ap-southeast-3'
}))

// Insert
await ddb.send(new PutCommand({
  TableName: 'Users',
  Item: { user_id: 'u1', email: 'alice@example.com', credits: 100 }
}))

// Get by primary key
const res = await ddb.send(new GetCommand({
  TableName: 'Users',
  Key: { user_id: 'u1' }
}))
console.log(res.Item)

// Atomic increment
await ddb.send(new UpdateCommand({
  TableName: 'Users',
  Key: { user_id: 'u1' },
  UpdateExpression: 'ADD credits :delta',
  ExpressionAttributeValues: { ':delta': -10 }
}))
```

## Gotcha

- **Partition key design menentukan scale**. PK yang hot (semua write ke 1 key) hit limit 1000 WCU per partition. Pakai PK dengan high cardinality.
- **Scan lambat dan mahal**. Pakai Query dengan PK, bukan Scan. Kalau butuh filter non-key, bikin GSI.
- **GSI bayar terpisah**. Tiap GSI consume WCU/RCU sendiri. 5 GSI = 6x cost write.
- **Item size max 400 KB**. Untuk data besar, simpan di S3, naro pointer (S3 key) di DynamoDB.
- **Transactional write 4x cost regular write**. TransactWriteItems = 2x cost write per item (commit phase). Pakai cuma kalau beneran butuh atomic.
- **PartiQL query mahal**: SELECT * tanpa WHERE pada PK = full scan. PartiQL convenient tapi cost-hungry kalau tidak hati-hati.
- **Reserved capacity tidak refundable**. 1 atau 3 tahun komitmen. Pakai cuma kalau traffic super-prediktabel.
- **DynamoDB Streams retention 24 jam**. Untuk arsip lebih panjang, integrate Lambda yang archive ke S3.
- **No native cross-region failover otomatis tanpa Global Tables**. App harus aware multi-region kalau pakai Global Tables (last-writer-wins resolution).
- **TTL delete eventual, bukan instant**. TTL field delete item dalam 48 jam dari expiry, bukan tepat di detik. Untuk hard delete on time, bikin Lambda scheduled.

## Cross-provider

| Provider | Service | Catatan |
|---|---|---|
| Azure | Cosmos DB | multi-model (key-value, document, graph), Global Tables built-in |
| GCP | Firestore | document model, sync ke client mobile/web bawaan |
| GCP | Bigtable | untuk volume PB, lebih low-level |
| Oracle | NoSQL Database | mirip DynamoDB, on-demand atau provisioned |
| Self-hosted | ScyllaDB, Cassandra | DynamoDB-compatible API |
