# ECS (Elastic Container Service)

**TL;DR**: Container orchestrator AWS native. Lebih simpel dari Kubernetes, tightly integrated ke ALB, IAM, CloudWatch. Dua launch type: **Fargate** (serverless, no EC2 manage) dan **EC2** (kamu manage cluster instance).

## Analogi

Mini-Kubernetes versi AWS. Tidak ada YAML 200 baris, tidak ada Helm chart, tidak ada controller plane yang harus operate. Tapi kalau workload kamu sudah pakai Helm + Operator, K8s lebih natural.

## Kapan pakai

- ✅ Containerized service (REST API, worker, scheduled job).
- ✅ Workload yang butuh long-running connection (WebSocket, gRPC).
- ✅ Migrate dari EC2 ke container tanpa pusing K8s.
- ✅ Simple microservice setup (3-10 service, single team).
- ✅ Scheduled task via Fargate Task (alternative cron job).

## Kapan jangan

- ❌ Workload sederhana per-request. Lambda lebih murah dan simpel.
- ❌ Multi-team multi-tenant dengan governance kompleks. Pakai EKS.
- ❌ Need K8s-specific tooling (Helm, Operators, ArgoCD, Istio).
- ❌ Mau workload portable cross-cloud. K8s lebih standar.

## Komponen

| Konsep | Fungsi |
|---|---|
| **Cluster** | logical grouping. Free di Fargate, butuh EC2 di EC2 launch type. |
| **Task Definition** | blueprint container (image, CPU, memory, env). Versioned. |
| **Task** | running instance dari task definition. |
| **Service** | ensure N task running, restart kalau crash, attach ke ALB. |
| **Launch type** | Fargate (serverless) atau EC2 (managed by you). |

## Fargate vs EC2 launch type

| Aspek | Fargate | EC2 |
|---|---|---|
| Ops effort | minimal | manage AMI, patching, scaling node |
| Cost | flat per vCPU + memory | lebih murah di scale tinggi |
| Resource granularity | task-level | node-level (bin-pack) |
| Spot capable | iya | iya, lebih predictable |
| GPU | terbatas | full support |
| Daemon set (sidecar host-level) | tidak | iya |
| Host volume | tidak | iya |

**Aturan praktis**: mulai Fargate. Pindah ke EC2 kalau cost dominan atau butuh capability host-level.

## Pricing mental model

### Fargate

| Komponen | Harga (us-east-1) |
|---|---|
| vCPU per jam | $0.04048 |
| Memory per GB per jam | $0.004445 |
| Spot | sekitar sama, tergantung region |
| Graviton (ARM) | 20% lebih murah |

Task dengan 0.25 vCPU + 0.5 GB RAM = ~$8.85/bulan running 24/7.

### EC2 launch type

Bayar instance EC2 standard. ECS sendiri gratis.

## Local emulator

**Floci status**: ✅ full (real Docker container spawn), Floci-exclusive

Task di ECS Floci spawn beneran via Docker socket. Bisa di-`docker ps`, di-`docker logs`. Lihat [J8 Container Workload](/id/aws/journeys/j8-container) untuk setup penuh.

## Hello-world

```bash
# Cluster
awsl ecs create-cluster --cluster-name demo

# Task definition (JSON inline)
awsl ecs register-task-definition \
  --family hello \
  --network-mode awsvpc \
  --requires-compatibilities FARGATE \
  --cpu 256 --memory 512 \
  --execution-role-arn arn:aws:iam::000000000000:role/ecsTaskExecutionRole \
  --container-definitions '[{
    "name": "app",
    "image": "nginx:alpine",
    "portMappings": [{"containerPort": 80, "protocol": "tcp"}],
    "essential": true
  }]'

# Service (jaga 1 task running)
awsl ecs create-service \
  --cluster demo \
  --service-name hello-svc \
  --task-definition hello \
  --desired-count 1 \
  --launch-type FARGATE \
  --network-configuration 'awsvpcConfiguration={subnets=[subnet-x],securityGroups=[sg-x],assignPublicIp=ENABLED}'
```

Cek task:

```bash
awsl ecs list-tasks --cluster demo
docker ps | grep nginx
```

## Gotcha

- **Fargate CPU/Memory matrix fixed**: 256 CPU bisa pair 512 MB sampai 2 GB. Tidak bebas kombinasi.
- **awsvpc = 1 ENI per task**: tiap task pakai 1 IP private subnet. Subnet kecil = limit task. Pakai /24+ subnet.
- **Task definition immutable**: ubah image atau env butuh bikin revision baru (`hello:2`). Update service untuk pakai revision baru.
- **Service rolling update default 200%/100%**: spin task baru sampai 200% desired, lalu drain task lama. Pastikan resource cukup, atau set 100%/50%.
- **Health check ALB lebih strict dari readiness probe K8s**: kalau /health timeout, task di-mark unhealthy dan di-restart. Beda sama EKS readinessProbe.
- **Spot Fargate bisa interrupt**: 2 menit warning. App harus handle SIGTERM graceful. Tidak cocok untuk stateful tanpa drain.
- **Container terminate timeout default 30 detik**: SIGTERM lalu 30 detik, baru SIGKILL. App harus drain connection cepat.
- **Log driver awslogs default**: ke CloudWatch Logs. Untuk routing custom (Datadog, Splunk), pakai FireLens (Fluent Bit).
- **Task role vs execution role**: execution role untuk Fargate pull image dan write log. Task role untuk container code akses AWS service.
- **Service Discovery (CloudMap) extra**: untuk service-to-service via DNS, setup CloudMap private namespace.
