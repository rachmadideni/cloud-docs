# Route53

**TL;DR**: Managed DNS dari AWS. Hosted zone $0.50/bulan flat per domain. Support routing policy advanced (weighted, latency-based, geo, failover). Tight integration ke service AWS (alias record gratis, sehat-check otomatis).

## Analogi

Buku telepon internet. Orang ingat `google.com`, internet butuh IP `172.217.x.x`. Route53 yang terjemah.

## Kapan pakai

- ✅ Domain registrar untuk new domain.
- ✅ DNS untuk app yang host di AWS (alias record ke CloudFront, ALB, S3 website).
- ✅ Multi-region failover dengan health check.
- ✅ Weighted routing untuk canary deploy (1% traffic ke versi baru).
- ✅ Latency-based routing untuk app multi-region.
- ✅ Geo routing untuk compliance (user EU diarahkan ke endpoint EU).
- ✅ Private DNS di VPC (Route53 Resolver).

## Kapan jangan

- ❌ DNS untuk domain di registrar lain yang punya DNS bundled. Cloudflare DNS free dan lebih cepat.
- ❌ Sub-millisecond DNS resolution requirement. Setup resolver internal.

## Pricing mental model

| Komponen | Harga |
|---|---|
| Hosted zone | $0.50/bulan per zone (12 zone pertama), $0.10/bulan setelahnya |
| Standard query | $0.40 per 1 juta query (1 miliar pertama/bulan) |
| Geo / latency / failover query | $0.70 per 1 juta query |
| Health check standard | $0.50/bulan per endpoint, $1.00 untuk HTTPS dengan string match |
| Domain registration | $9-$500/tahun tergantung TLD |
| Alias record query | gratis (ke service AWS) |

Untuk app kecil dengan 1 domain: ~$1-3/bulan total. Tidak signifikan.

## Local emulator

**Floci status**: ✅ full (Floci-exclusive vs LocalStack Free)

```bash
# Bikin hosted zone
awsl route53 create-hosted-zone --name example.com \
  --caller-reference $(date +%s)

# Bikin record
awsl route53 change-resource-record-sets \
  --hosted-zone-id ZONE_ID \
  --change-batch '{
    "Changes": [{
      "Action": "CREATE",
      "ResourceRecordSet": {
        "Name": "api.example.com",
        "Type": "A",
        "TTL": 300,
        "ResourceRecords": [{"Value": "1.2.3.4"}]
      }
    }]
  }'
```

DNS resolution lokal tidak benar-benar resolve (Floci tidak handle DNS port 53 untuk client lokal). Pakai untuk test API call create/list/update record.

## Hello-world

```bash
# List hosted zone
awsl route53 list-hosted-zones

# Bikin A record
awsl route53 change-resource-record-sets \
  --hosted-zone-id Z123 \
  --change-batch file://change.json
```

`change.json`:

```json
{
  "Changes": [{
    "Action": "UPSERT",
    "ResourceRecordSet": {
      "Name": "app.example.com",
      "Type": "A",
      "AliasTarget": {
        "HostedZoneId": "Z2FDTNDATAQYW2",
        "DNSName": "d111111abcdef8.cloudfront.net",
        "EvaluateTargetHealth": false
      }
    }
  }]
}
```

Alias record (`AliasTarget`) point ke CloudFront. Gratis query, tidak seperti CNAME standard.

## Gotcha

- **TTL trade-off**: TTL kecil (60s) artinya update cepat propagate tapi traffic query naik. TTL besar (1 jam) artinya hemat tapi lambat propagate. Untuk failover, set TTL kecil (60s).
- **Alias vs CNAME**: Alias bisa di root domain (`example.com`), CNAME tidak bisa di apex (cuma subdomain). Alias gratis query, CNAME charged.
- **NS record di apex tidak boleh diubah**: name server harus tetap di-set ke 4 AWS NS yang otomatis dibuat saat create zone.
- **Domain transfer tidak boleh dalam 60 hari setelah register/transfer**: hard rule registrar industry, bukan Route53.
- **Health check evaluate dari beberapa region AWS**: kalau endpoint kamu cuma allow IP tertentu, izinkan IP range Route53 health checker.
- **Private hosted zone tidak resolve dari internet**: cuma resolve dari VPC yang di-attach.
- **Subdomain delegation**: untuk delegasikan `api.example.com` ke zone terpisah, bikin NS record di parent zone yang point ke child zone NS.
- **Apex domain (root) wajib alias atau A record**: tidak bisa CNAME apex per RFC. Pakai Route53 Alias.
- **DNSSEC opt-in**: setup butuh KMS key plus konfigurasi di registrar. Worth untuk domain bisnis.
- **Latency-based routing membutuhkan akurasi geo IP**: kadang user kena edge region jauh karena ISP routing mereka aneh. Mix dengan geo routing kalau perlu deterministic.
