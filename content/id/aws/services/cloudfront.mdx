# CloudFront

**TL;DR**: CDN AWS dengan 400+ edge location global. Cache static dan dynamic content dekat user, percepat delivery, kurangi load origin. Free tier 1 TB egress/bulan permanen (sejak 2021).

## Analogi

Toko cabang. Pelanggan tidak perlu pergi ke gudang pusat (origin S3 atau EC2) untuk ambil barang. Toko cabang terdekat (edge location) punya stok sering-diminta. Kalau stok kosong, baru request ke gudang.

## Kapan pakai

- ✅ Static website hosting bareng S3 (HTML, CSS, JS, image).
- ✅ Asset delivery aplikasi (avatar, thumbnail, video).
- ✅ API caching di depan API Gateway atau ALB (untuk endpoint GET).
- ✅ Video on-demand atau live streaming (dengan MediaPackage).
- ✅ Software download distribution.
- ✅ DDoS protection level 3/4 built-in (Shield Standard gratis).
- ✅ SSL termination plus HTTPS upgrade untuk origin HTTP.

## Kapan jangan

- ❌ API endpoint dengan response selalu unique per user (cache hit rate rendah).
- ❌ Real-time streaming dengan latency sub-detik (WebRTC pakai service lain).
- ❌ Traffic super-local (semua user di 1 kota). Overhead CloudFront tidak sebanding.

## Pricing mental model

3 komponen:

| Komponen | Harga |
|---|---|
| Data transfer out | $0.085/GB (1 TB pertama gratis selamanya), turun di volume tinggi |
| HTTP/HTTPS request | $0.0075 per 10.000 HTTP, $0.01 per 10.000 HTTPS |
| Invalidation | 1000 path/bulan gratis, $0.005 per path setelahnya |

Sticker shock:
- **Invalidation per file**: deploy yang invalidate ribuan file = ratusan dolar. Pakai versioned filename (Next.js static export auto-hash).
- **Real-time logs**: $0.01 per 1 juta log line. Untuk traffic tinggi, mahal.

## Local emulator

**Floci status**: ❌ gap

Fallback lokal: **nginx** sebagai reverse proxy + cache headers.

```nginx
# nginx.conf
http {
  proxy_cache_path /tmp/cache levels=1:2 keys_zone=cdn:10m max_size=100m;

  server {
    listen 80;
    location / {
      proxy_pass http://host.docker.internal:4566/my-bucket/;
      proxy_cache cdn;
      proxy_cache_valid 200 5m;
      add_header X-Cache $upstream_cache_status;
    }
  }
}
```

Walau nginx tidak punya 400 edge location, perilaku cache HIT/MISS bisa di-test. Lihat [J1 Static Site](/id/aws/journeys/j1-static-site) untuk setup penuh.

## Hello-world

Bikin distribution dengan origin S3:

```bash
# AWS asli (Floci gap)
aws cloudfront create-distribution \
  --origin-domain-name my-bucket.s3.amazonaws.com \
  --default-root-object index.html
```

Propagation 15-30 menit. Setelah selesai, akses `https://xxxxx.cloudfront.net`.

## Gotcha

- **Propagation lambat**: bikin atau update distribution butuh 15-30 menit untuk propagate ke semua edge. Tidak instan seperti S3 atau Lambda.
- **Cache invalidation tidak instan**: invalidation request butuh beberapa menit untuk effective di semua edge.
- **ACM cert wajib di us-east-1**: untuk attach custom domain ke CloudFront, ACM cert harus di-create di region us-east-1, tidak peduli user kamu di mana.
- **Origin Access Identity (OAI) vs Origin Access Control (OAC)**: OAC adalah generasi baru (2022+), support semua region S3 dan KMS encryption. OAI legacy. Pakai OAC untuk distribution baru.
- **HTTPS to origin**: enable end-to-end encryption. Origin S3 atau ALB pakai HTTPS, CloudFront pakai HTTPS ke origin juga.
- **Edge location bukan database**: jangan asumsi data konsisten di semua edge. Cache invalidation atau TTL expiry yang sync.
- **Geo restriction**: bisa block country tertentu, atau allowlist. Compliance regulasi data residency.
- **Real IP user**: backend liat `X-Forwarded-For` header, bukan source IP request (yang CloudFront edge IP). Adjust app logging.
- **Cache key default exclude query string dan header**: untuk cache variant per locale atau auth, set Cache Policy explicit include header/query.
- **SPA routing 404**: CloudFront kembalikan 404 untuk path `/about` kalau S3 tidak ada object `about`. Set custom error page yang redirect ke `/index.html` untuk SPA client-side routing.
