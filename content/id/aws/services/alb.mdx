# ALB (Application Load Balancer)

**TL;DR**: Layer 7 (HTTP/HTTPS) load balancer. Route traffic ke EC2/ECS/Lambda/IP target berdasarkan path, host, header. SSL termination, health check, WebSocket native. Sister: NLB (layer 4 TCP/UDP) dan GLB (Gateway, layer 3).

## Analogi

Resepsionis pintar yang baca isi surat sebelum forward ke department. ALB tahu HTTP method, path, header. Beda dari NLB yang cuma lihat IP + port.

## Kapan pakai

- ✅ HTTP/HTTPS service yang butuh path-based routing (`/api` ke service A, `/static` ke service B).
- ✅ Host-based routing (multi-tenant per subdomain).
- ✅ SSL termination dengan ACM cert.
- ✅ Health check application-level (cek `/health` endpoint).
- ✅ WebSocket dan HTTP/2.
- ✅ Sticky session via cookie.
- ✅ Direct integration ke Lambda (no API Gateway).
- ✅ ECS/EKS target group.

## Kapan jangan

- ❌ TCP/UDP non-HTTP traffic. Pakai NLB.
- ❌ Sub-ms latency requirement. Pakai NLB (lebih cepat).
- ❌ Static content cache. Pakai CloudFront di depan ALB.
- ❌ Single-region serverless dengan Lambda saja. Pakai API Gateway HTTP API (lebih simpel).
- ❌ Internal service mesh. Pakai Cloud Map atau Istio.

## Pricing mental model

| Komponen | Harga (us-east-1) |
|---|---|
| ALB-hour | $0.0225/jam (~$16/bulan idle) |
| LCU-hour | $0.008/jam, scale dengan traffic |

LCU dihitung dari 4 dimensi (new connection, active connection, processed bytes, rule evaluation). Bayar yang tertinggi. Idle ALB cuma kena hour cost. Traffic tinggi kena LCU naik.

Contoh: ALB dengan 100 req/detik average, payload 10 KB = ~1 LCU/jam = $5.76/bulan tambahan. Total ~$22/bulan.

## Local emulator

**Floci status**: ✅ full (ALB + NLB), Floci-exclusive vs LocalStack Free

```bash
ALB_ARN=$(awsl elbv2 create-load-balancer \
  --name demo-alb \
  --subnets subnet-1 subnet-2 \
  --security-groups sg-x \
  --scheme internet-facing --type application \
  --query 'LoadBalancers[0].LoadBalancerArn' --output text)

TG_ARN=$(awsl elbv2 create-target-group \
  --name demo-tg --protocol HTTP --port 80 \
  --target-type ip --vpc-id vpc-x \
  --health-check-path /health \
  --query 'TargetGroups[0].TargetGroupArn' --output text)

awsl elbv2 create-listener \
  --load-balancer-arn $ALB_ARN \
  --protocol HTTP --port 80 \
  --default-actions Type=forward,TargetGroupArn=$TG_ARN
```

## Hello-world

Path-based routing: `/api` ke service A, `/web` ke service B.

```bash
# Tambah listener rule dengan priority
awsl elbv2 create-rule \
  --listener-arn $LISTENER_ARN \
  --priority 10 \
  --conditions Field=path-pattern,Values='/api/*' \
  --actions Type=forward,TargetGroupArn=$TG_A

awsl elbv2 create-rule \
  --listener-arn $LISTENER_ARN \
  --priority 20 \
  --conditions Field=path-pattern,Values='/web/*' \
  --actions Type=forward,TargetGroupArn=$TG_B
```

HTTPS dengan ACM:

```bash
awsl elbv2 create-listener \
  --load-balancer-arn $ALB_ARN \
  --protocol HTTPS --port 443 \
  --certificates CertificateArn=$ACM_ARN \
  --default-actions Type=forward,TargetGroupArn=$TG_ARN
```

Redirect HTTP ke HTTPS:

```bash
awsl elbv2 create-listener \
  --load-balancer-arn $ALB_ARN \
  --protocol HTTP --port 80 \
  --default-actions 'Type=redirect,RedirectConfig={Protocol=HTTPS,Port=443,StatusCode=HTTP_301}'
```

## Gotcha

- **target-type ip untuk Fargate**: ECS Fargate task tidak punya EC2 instance, harus pakai `target-type ip`. Default `instance` cuma works untuk EC2.
- **Health check timeout strict**: kalau target return non-2xx 3x berturut (default), di-mark unhealthy. ALB stop route ke target itu. Tuning interval/threshold sesuai cold start app.
- **ALB tidak punya static IP**: pakai DNS name. Untuk static IP, pakai NLB atau Global Accelerator.
- **Connection draining default 300 detik**: scale-down task di-keep alive 5 menit untuk drain in-flight request. Sesuaikan untuk app dengan request lama.
- **Listener rule priority unique**: tidak boleh duplicate priority. Kalau bentrok, deploy fail.
- **WAF attach per ALB**: Web Application Firewall di-attach langsung. Beda dari CloudFront yang WAF di-attach ke distribution.
- **Cross-zone load balancing default ON**: ALB distribute traffic ke target di semua AZ. NLB default OFF (per-AZ). Cek setting.
- **SNI default untuk HTTPS**: 1 listener bisa serve multiple cert via SNI. Default cert untuk client yang tidak support SNI (rare).
- **WebSocket sticky session via cookie atau target group config**: client harus konek ke task sama. Set `stickiness.enabled=true` di target group.
- **ALB tidak support gRPC streaming penuh**: support unary gRPC. Untuk bidirectional streaming, pakai NLB atau service mesh.
