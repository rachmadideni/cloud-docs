# EKS (Elastic Kubernetes Service)

**TL;DR**: Managed Kubernetes control plane. AWS jalankan etcd, API server, scheduler. Kamu manage workload via `kubectl` standard. Control plane $73/bulan flat plus worker node cost. Pakai untuk multi-team, multi-service, atau workload yang butuh ekosistem K8s.

## Analogi

Kubernetes vanilla tanpa harus install dan operate sendiri. AWS jadi DevOps team yang jaga master node, kamu fokus deploy app.

## Kapan pakai

- ✅ Multi-team multi-service organization yang butuh namespace + RBAC isolation.
- ✅ Workload portable cross-cloud (K8s manifest jalan di EKS, GKE, AKS, on-prem).
- ✅ Stack yang sudah pakai Helm, ArgoCD, Operators.
- ✅ Service mesh (Istio, Linkerd) untuk mTLS internal.
- ✅ Workload yang butuh sidecar pattern (Envoy, logging agent).
- ✅ Hybrid scheduling (CPU + GPU pod di cluster sama).

## Kapan jangan

- ❌ Single workload simpel. Pakai ECS Fargate atau App Runner.
- ❌ Team kecil tanpa K8s knowledge. Learning curve curam.
- ❌ Workload serverless per-request. Lambda lebih murah.
- ❌ Dev/staging environment dengan budget ketat. Control plane $73/bulan = mahal untuk idle cluster.

## Pricing mental model

| Komponen | Harga (us-east-1) |
|---|---|
| Control plane | $0.10/jam = **$73/bulan per cluster** |
| Worker node (EC2) | EC2 standard pricing (t3.medium ~$30/bulan) |
| Worker node (Fargate) | Fargate pricing per pod |
| EBS root volume | $0.08/GB/bulan gp3 |
| ALB (Ingress) | ~$16/bulan + traffic |
| EKS Auto Mode (2024+) | bundled node + control plane, lebih murah small cluster |

Cluster minimum: $73 (CP) + $90 (3 t3.medium) + $5 (EBS) + $16 (ALB) = **$185/bulan**.

## Local emulator

**Floci status**: ✅ full (real k3s cluster), Floci-exclusive vs LocalStack Free

k3s = distribusi Kubernetes ringan. `kubectl` standard works.

```bash
eksctl create cluster --name demo --region us-east-1 \
  --version 1.30 --nodes 2 --node-type t3.medium --managed
# Atau raw:
awsl eks create-cluster --name demo --version 1.30 \
  --role-arn arn:aws:iam::000000000000:role/eks-role \
  --resources-vpc-config subnetIds=subnet-1,subnet-2

awsl eks update-kubeconfig --name demo
kubectl get nodes
```

## Hello-world

Deploy nginx:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx
spec:
  replicas: 2
  selector: { matchLabels: { app: nginx } }
  template:
    metadata: { labels: { app: nginx } }
    spec:
      containers:
      - name: nginx
        image: nginx:alpine
        ports: [{ containerPort: 80 }]
---
apiVersion: v1
kind: Service
metadata: { name: nginx }
spec:
  type: ClusterIP
  selector: { app: nginx }
  ports: [{ port: 80 }]
```

```bash
kubectl apply -f deploy.yaml
kubectl get pods
```

Untuk Ingress + ALB, install AWS Load Balancer Controller via Helm (lihat [J9 Kubernetes](/id/aws/journeys/j9-kubernetes)).

## Gotcha

- **Control plane idle = bayar tetap**: $73/bulan tidak peduli pod count 0 atau ribuan. Untuk dev, pakai kind/k3s lokal atau EKS Auto Mode.
- **IRSA setup butuh OIDC provider**: enable saat create cluster (`--with-oidc` di eksctl). Tanpa OIDC, pod akses AWS lewat node role (less secure).
- **VPC CNI IP exhaustion**: default Amazon VPC CNI assign 1 ENI + multiple IP per pod. t3.medium = 18 IP max. Pod density rendah. Tuning `WARM_ENI_TARGET` atau pakai Cilium.
- **Cluster Autoscaler reaktif lambat**: scan tiap 10 detik, scale-down 10 menit. Karpenter jauh lebih cepat (sub-minute).
- **PodDisruptionBudget wajib produksi**: tanpa PDB, node drain ambil semua pod sekaligus. Set `minAvailable: 1`.
- **EKS Fargate vs EC2 node**: Fargate per pod (lebih mahal, tidak ada DaemonSet, max pod size 16 vCPU/120 GB). EC2 untuk bulk workload.
- **kubeconfig versioning**: AWS update CLI token format. Update kubectl + aws-cli compatible.
- **Major K8s version upgrade**: support 4 latest version. Older deprecated. Plan upgrade tiap 12 bulan.
- **Helm chart version drift**: pin version eksplisit. Pakai GitOps (ArgoCD/Flux) untuk drift detection.
- **NodePort vs LoadBalancer vs Ingress**: NodePort untuk dev, LoadBalancer = NLB per service (mahal), Ingress + ALB Controller untuk multiple service share 1 ALB.
