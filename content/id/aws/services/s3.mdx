# S3 (Simple Storage Service)

**TL;DR**: Object storage scalable tanpa batas, durable 11 nines (99.999999999%), bayar per GB tersimpan plus per request. Tempat default untuk file, backup, data lake, dan static website hosting.

## Analogi

Bayangkan Google Drive untuk aplikasi, tapi tanpa quota dan dengan API. Folder digantikan "prefix" di nama file. Tidak ada konsep file system tradisional (rename folder bukan operasi atomic).

## Kapan pakai

- ✅ File upload dari user (foto, dokumen, video).
- ✅ Backup database, snapshot EBS, log archive.
- ✅ Static website hosting (HTML, CSS, JS, image).
- ✅ Data lake untuk analytics (Parquet, JSON, CSV).
- ✅ Asset delivery di belakang CloudFront CDN.
- ✅ Build artifact, container image layer (bukan ECR, tapi ECR backend pakai S3).
- ✅ Storage untuk Lambda layer, CloudFormation template, training dataset.

## Kapan jangan

- ❌ Database dengan query SQL. S3 tidak ada index, query lambat tanpa engine khusus.
- ❌ Edit file frequent. S3 immutable, "edit" = replace file utuh.
- ❌ File system mount yang butuh POSIX semantics (file locking, atomic rename). Pakai EFS atau FSx.
- ❌ Storage low-latency sub-ms. S3 latency 50-200 ms. Untuk cache pakai ElastiCache.
- ❌ Streaming media yang butuh adaptive bitrate. Pakai MediaPackage atau CloudFront streaming.

## Pricing mental model

Tiga komponen utama:

| Komponen | Dimensi | Skala |
|---|---|---|
| Storage | GB per bulan per storage class | $0.023/GB Standard, $0.004 Glacier IR, $0.00099 Glacier Deep Archive |
| Request | per 1000 atau per 10000 | PUT lebih mahal dari GET |
| Transfer | GB egress ke internet atau cross-region | $0.09/GB internet, $0.02/GB cross-region |

Yang sering bikin tagihan kaget:
- **Bucket dengan jutaan small file**: tiap object kena minimum charge.
- **List operation di bucket besar**: $0.005 per 1000 list. Crawl-like operation bisa mahal.
- **Cross-region replication**: bayar storage di dua region plus transfer.

Storage class:
- **Standard**: data sering diakses.
- **Intelligent-Tiering**: AWS otomatis pindahkan ke tier murah kalau jarang diakses. Default untuk data unpredictable.
- **Infrequent Access (IA)**: cheap storage, retrieval fee. Untuk file lama yang kadang dibutuhkan.
- **Glacier Instant Retrieval**: archive dengan retrieval cepat (ms).
- **Glacier Flexible Retrieval**: archive 1-5 menit retrieval.
- **Glacier Deep Archive**: cheapest, retrieval butuh 12-48 jam.

## Hello-world

```bash
# Bikin bucket
awsl s3 mb s3://demo-bucket

# Upload file
echo "hello s3" > hello.txt
awsl s3 cp hello.txt s3://demo-bucket/

# List
awsl s3 ls s3://demo-bucket/

# Download
awsl s3 cp s3://demo-bucket/hello.txt downloaded.txt
cat downloaded.txt
```

Presigned URL untuk upload langsung dari browser tanpa expose credential:

```js
const { S3Client, PutObjectCommand } = require('@aws-sdk/client-s3')
const { getSignedUrl } = require('@aws-sdk/s3-request-presigner')

const s3 = new S3Client({ region: 'ap-southeast-3' })
const cmd = new PutObjectCommand({
  Bucket: 'demo-bucket',
  Key: 'uploads/file.jpg',
  ContentType: 'image/jpeg'
})
const url = await getSignedUrl(s3, cmd, { expiresIn: 300 })
// kasih ke browser, browser PUT ke `url` langsung
```

## Gotcha

- **Bucket name unik global**. `my-bucket` mungkin sudah dipakai akun lain. Pakai prefix unik: `<company>-<purpose>-<env>`.
- **Eventually consistent untuk list, strongly consistent untuk read/write per object** (sejak 2020). Read setelah PUT immediate return data baru, tapi LIST baru muncul setelah delay singkat.
- **Default private**. Bucket baru tidak public. Untuk static website hosting public, set bucket policy plus disable Block Public Access. Hati-hati tidak accidental public bucket.
- **No folder concept beneran**. Folder cuma prefix. Hapus "folder" = hapus semua object dengan prefix itu. Rename folder = copy semua object lalu hapus original (mahal).
- **Versioning + Lifecycle bisa tricky**. Aktifkan versioning artinya delete tidak hapus beneran (bikin "delete marker"). Tanpa lifecycle policy, storage cost naik diam-diam.
- **Cross-region replication bukan backup**. CRR async, delete di source replicate ke target. Untuk backup proper, pakai S3 Object Lock atau cross-account snapshot.
- **Multipart upload untuk file besar**. File lebih dari 5 GB wajib multipart. SDK auto-handle, tapi kalau abort upload tanpa cleanup, part-part sisa kena charge storage. Set lifecycle rule clean incomplete multipart.
- **Bucket policy vs IAM policy**: bucket policy nempel di bucket, IAM policy nempel di principal. Bisa konflik. Deny menang. Pakai IAM Policy Simulator untuk debug.
- **Pre-signed URL bisa di-replay sebelum expire**. Jangan log URL ini. Set expiry pendek (1-5 menit).
