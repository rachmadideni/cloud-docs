# Compose Recipes

Copy-paste docker-compose.yml siap pakai per journey. Mulai minimal (cuma Floci), tambah service tambahan sesuai kebutuhan.

## Base (semua journey)

Compose minimal untuk semua journey:

```yaml
# docker-compose.yml
services:
  floci:
    image: floci/floci:latest
    ports: ['4566:4566']
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:4566/_localstack/health"]
      interval: 10s
      timeout: 5s
      retries: 5
```

```bash
docker compose up -d
```

Healthcheck supaya `depends_on` di service lain bisa wait Floci ready.

## J1: Static Site

Floci + nginx untuk CloudFront fallback + HTTPS termination.

```yaml
services:
  floci:
    image: floci/floci:latest
    ports: ['4566:4566']
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock

  nginx:
    image: nginx:alpine
    ports:
      - '443:443'
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./certs:/etc/nginx/certs:ro
    depends_on: [floci]
    extra_hosts:
      - 'host.docker.internal:host-gateway'   # Linux
```

```nginx
# nginx.conf
events {}

http {
  proxy_cache_path /tmp/cache levels=1:2 keys_zone=cdn:10m max_size=100m;

  server {
    listen 443 ssl;
    server_name app.local;
    ssl_certificate     /etc/nginx/certs/app.local.crt;
    ssl_certificate_key /etc/nginx/certs/app.local.key;

    location / {
      proxy_pass http://host.docker.internal:4566/my-bucket/;
      proxy_cache cdn;
      proxy_cache_valid 200 1m;
      add_header X-Cache $upstream_cache_status;
    }
  }
}
```

Setup cert:

```bash
mkcert -install
mkdir certs
mkcert -cert-file certs/app.local.crt -key-file certs/app.local.key app.local
```

## J10: Observability (X-Ray fallback Jaeger)

Floci + Jaeger.

```yaml
services:
  floci:
    image: floci/floci:latest
    ports: ['4566:4566']
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock

  jaeger:
    image: jaegertracing/all-in-one:latest
    ports:
      - '16686:16686'   # UI
      - '4317:4317'     # OTLP gRPC
      - '4318:4318'     # OTLP HTTP
    environment:
      COLLECTOR_OTLP_ENABLED: 'true'
```

Akses Jaeger UI: `http://localhost:16686`.

Lambda env var: `OTEL_EXPORTER_OTLP_ENDPOINT=http://jaeger:4318/v1/traces`.

## Master stack (semua service)

Compose lengkap untuk dev environment yang cover semua journey:

```yaml
# docker-compose.yml
services:
  floci:
    image: floci/floci:latest
    ports: ['4566:4566']
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:4566/_localstack/health"]
      interval: 10s
      timeout: 5s
      retries: 5

  # J1 fallback: CloudFront
  nginx:
    image: nginx:alpine
    profiles: [j1, full]
    ports: ['443:443']
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./certs:/etc/nginx/certs:ro

  # J10 fallback: X-Ray
  jaeger:
    image: jaegertracing/all-in-one:latest
    profiles: [j10, full]
    ports: ['16686:16686', '4317:4317', '4318:4318']
    environment:
      COLLECTOR_OTLP_ENABLED: 'true'

  # J12 fallback: Bedrock LLM
  ollama:
    image: ollama/ollama:latest
    profiles: [j12, full]
    ports: ['11434:11434']
    volumes:
      - ollama-data:/root/.ollama

  # J12 vector DB
  qdrant:
    image: qdrant/qdrant:latest
    profiles: [j12, full]
    ports: ['6333:6333']
    volumes:
      - qdrant-data:/qdrant/storage

  # SES fallback
  mailpit:
    image: axllent/mailpit:latest
    profiles: [ses, full]
    ports: ['1025:1025', '8025:8025']

  # Database GUI (J6)
  pgadmin:
    image: dpage/pgadmin4:latest
    profiles: [j6, full]
    ports: ['5050:80']
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@local.dev
      PGADMIN_DEFAULT_PASSWORD: admin
    volumes:
      - pgadmin-data:/var/lib/pgadmin

volumes:
  ollama-data:
  qdrant-data:
  pgadmin-data:
```

Profile-based: cuma start service yang dibutuhkan:

```bash
# Cuma Floci
docker compose up -d

# J1 (Floci + nginx)
docker compose --profile j1 up -d

# J12 (Floci + Ollama + Qdrant)
docker compose --profile j12 up -d

# Semua
docker compose --profile full up -d
```

## Networking tip

### Linux: host.docker.internal

Default tidak resolve. Tambah di service yang butuh akses host:

```yaml
services:
  myapp:
    extra_hosts:
      - 'host.docker.internal:host-gateway'
```

### Mac/Windows

Auto-resolve. Tidak butuh extra_hosts.

### Antar service di compose

Service akses via service name. `floci`, `ollama`, `qdrant`. Tidak butuh `host.docker.internal` antar service di compose sama.

## Persistence

Default container ephemeral. Restart Floci = data hilang.

Untuk persist data Floci:

```yaml
services:
  floci:
    image: floci/floci:latest
    ports: ['4566:4566']
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - floci-data:/var/lib/floci   # tambah ini

volumes:
  floci-data:
```

Pro/cons:
- Pro: data survive `docker compose down`.
- Cons: state lama bisa cause test inconsistency. Untuk integration test, prefer ephemeral.

Wipe data:

```bash
docker compose down -v   # -v hapus volume
```

## Performance tuning

Compose berat (banyak service) bisa lambat startup. Tip:

- **Pull image dulu**: `docker compose pull` sebelum `up`. Cache image lokal.
- **Resource Docker Desktop**: allocate 4-8 GB RAM, 4-8 CPU di settings.
- **Healthcheck dengan depends_on**: service tunggu dependency healthy sebelum start. Hindari race condition.
- **Profile**: jangan start semua service kalau cuma butuh subset.
- **Cache layer**: pakai bind mount untuk node_modules atau pip cache di build context.

```yaml
services:
  myapp:
    build: .
    depends_on:
      floci:
        condition: service_healthy
```

## Troubleshooting

### Port already in use

```bash
# Cek proses
lsof -i :4566   # Mac/Linux
netstat -ano | findstr 4566   # Windows

# Atau ganti port di compose
ports: ['4567:4566']
```

### Service start tapi exit

```bash
docker compose logs <service-name>
# Lihat error
```

### Compose cache stale

```bash
docker compose down
docker compose build --no-cache
docker compose up
```

### Image update tidak applied

```bash
docker compose pull
docker compose up -d --force-recreate
```
