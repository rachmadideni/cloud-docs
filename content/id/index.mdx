# Cloud Docs

Dokumentasi cloud services komprehensif — AWS, Azure, GCP, Oracle — dengan insight, perfect use-case, dan local emulator setup.

## Filosofi

- **Use-case journey first**: kamu belajar service ketika butuh di konteks nyata, bukan daftar abjad.
- **Local-first**: tiap journey runnable di laptop pakai emulator ([floci.io](https://floci.io) untuk AWS).
- **Cross-provider**: tiap konsep punya mapping ke semua provider — pindah cloud tidak start from zero.
- **Bilingual**: Bahasa Indonesia default, English mirror.

## Mulai dari mana?

- Baru kenal cloud? → [Fondasi](/id/foundation)
- Mau bikin sesuatu? → [Use-Case Journey](/id/journeys)
- Cari service spesifik? → [Service Reference](/id/services)
