## Filosofi

- **Use-case journey first**: kamu belajar service ketika butuh di konteks nyata, bukan daftar abjad.
- **Local-first**: tiap journey runnable di laptop pakai emulator (floci untuk AWS, `supabase start` untuk Supabase).
- **Cross-provider**: tiap konsep punya mapping ke provider lain, pindah cloud tidak start from zero.
- **Bilingual**: Bahasa Indonesia default, English mirror.
