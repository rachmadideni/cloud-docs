- [Compose Recipes](/id/tools/compose-recipes), docker-compose siap pakai per journey

- [Dev Workflow](/id/tools/dev-workflow), daily pattern + useful CLI tool

## Mulai dari mana?

1. **Hari pertama**: install [AWS CLI](/id/tools/aws-cli) + Docker + clone repo.
2. **Setup Floci**: ikuti [Floci](/id/tools/floci).
3. **Pick journey**: pilih dari [Use-Case Journey](/id/journeys), pakai compose recipe yang sesuai.
4. **Iterate**: pakai [Dev Workflow](/id/tools/dev-workflow) pattern.
5. **Deploy**: setup [CI/CD](/id/tools/cicd) saat ready ke production.
