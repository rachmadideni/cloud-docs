| ID  | Journey | Highlight |
|-----|---|---|
| [J1](/id/journeys/j1-static-site) | Static site + custom domain | S3, CloudFront, Route53, ACM |
| [J2](/id/journeys/j2-rest-api) | REST API serverless | Lambda, API Gateway, DynamoDB |
| [J3](/id/journeys/j3-auth) | Auth & user mgmt | Cognito, IAM |
| [J4](/id/journeys/j4-file-upload) | File upload pipeline | S3 presigned, Lambda, SQS |
| [J5](/id/journeys/j5-event-driven) | Event-driven backend | EventBridge, SQS, Step Functions |
| [J6](/id/journeys/j6-relational) | Relational app | RDS Postgres, VPC |
| [J7](/id/journeys/j7-data-pipeline) | Data pipeline | Kinesis, Glue, Athena |
| [J8](/id/journeys/j8-container) | Container workload | ECR, ECS Fargate, ALB |
| [J9](/id/journeys/j9-kubernetes) | Kubernetes | EKS, ALB Controller |
| [J10](/id/journeys/j10-observability) | Observability | CloudWatch, X-Ray |
| [J11](/id/journeys/j11-security) | Security baseline | IAM, KMS, Secrets Manager |
