# Use-Case Journey

Belajar service cloud dari konteks problem nyata. Service muncul sesuai kebutuhan, bukan daftar abjad.

| ID  | Journey | Highlight |
|-----|---|---|
| [J1](/id/journeys/j1-static-site) | Static site + custom domain | S3, CloudFront, Route53, ACM |
| [J2](/id/journeys/j2-rest-api) | REST API serverless | Lambda, API Gateway, DynamoDB |
| [J3](/id/journeys/j3-auth) | Auth & user mgmt | Cognito, IAM |
| [J4](/id/journeys/j4-file-upload) | File upload pipeline | S3 presigned, Lambda, SQS |
| J5  | Event-driven backend | EventBridge, SQS, Step Functions |
| J6  | Relational app | RDS Postgres, VPC |
| J7  | Data pipeline | Kinesis, Glue, Athena |
| J8  | Container workload | ECR, ECS Fargate, ALB |
| J9  | Kubernetes | EKS, ALB Controller |
| J10 | Observability | CloudWatch, X-Ray |
| J11 | Security baseline | IAM, KMS, Secrets Manager |
| J12 | AI/ML inference | Bedrock, SageMaker |
