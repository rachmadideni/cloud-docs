# Supabase

Open-source BaaS di atas Postgres. Auth, database, storage, realtime, edge function, dan pgvector dalam satu project. Local dev real lewat `supabase start` (Docker compose internal).

> **Status: On Progress.** Konten masih skeleton. Halaman akan diisi bertahap mengikuti pola yang sama dengan section AWS (use-case journey + service deep page + tools).

## Target Service Reference

- Database (Postgres + ekstensi)
- Auth (JWT, OAuth, MFA)
- Storage (S3-compatible)
- Edge Functions (Deno)
- Realtime (Postgres CDC, broadcast, presence)
- Vector (pgvector)
- Studio (dashboard)

## Local Dev

`supabase start` jalanin full stack (Postgres + GoTrue + Storage + Realtime + Edge Runtime) via Docker compose. Single command, no manual setup. Detail di [Tools & Local Dev](/id/supabase/tools).
