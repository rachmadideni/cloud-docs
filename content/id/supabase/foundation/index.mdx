# Fondasi Supabase

> **Skeleton.** Halaman ini akan diisi dengan konsep dasar Supabase: project model, organisasi, environment (local / branch / prod), pricing mental model, dan glossary.

## Outline target

- **Project model**: 1 project = 1 Postgres database + service stack di sekelilingnya.
- **Organisasi**: project di-grup dalam organization untuk billing dan member.
- **Environment**: local (`supabase start`), branch preview, dan prod project.
- **Pricing mental model**: dimensi yang bikin tagihan naik (storage, egress, compute add-on, MAU auth).
- **Glossary**: RLS, GoTrue, PostgREST, Realtime broadcast vs CDC, Edge Runtime.

Sementara, lihat [docs resmi Supabase](https://supabase.com/docs) untuk konsep dasar.
