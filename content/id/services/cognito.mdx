# Cognito

**TL;DR**: Managed user authentication. User pool untuk registry user (signup, signin, MFA, social login). Identity pool untuk federated identity (issue temporary AWS credential). Free tier 10.000 MAU permanen, salah satu paling generous.

## Analogi

Auth0 atau Firebase Auth versi AWS. Bedanya: deep integration ke ekosistem AWS (IAM, API Gateway authorizer built-in), tapi UX/DX kurang polished dari competitor.

## Kapan pakai

- ✅ User registry untuk web/mobile app: signup, signin, password reset, email/phone verify.
- ✅ Social login (Google, Facebook, Apple, Microsoft).
- ✅ Federated identity dengan SAML/OIDC enterprise IdP.
- ✅ MFA (TOTP, SMS, WebAuthn).
- ✅ Token-based auth untuk API (JWT yang divalidate API Gateway native).
- ✅ Custom auth flow (passwordless, magic link via Lambda triggers).
- ✅ Identity pool untuk issue AWS credential ke mobile/web client (akses S3, DynamoDB langsung dari client).

## Kapan jangan

- ❌ Kalau ingin UX login yang sangat polished tanpa effort. Auth0/Clerk lebih baik di UI/dev experience.
- ❌ Aplikasi yang butuh fine-grained authorization policy (ABAC). Pakai service khusus seperti Permit.io atau OPA.
- ❌ Internal SSO untuk team kerja. Pakai AWS IAM Identity Center (former AWS SSO) atau Okta.
- ❌ B2B multi-tenancy dengan org/team yang kompleks. Frontegg, WorkOS lebih natural.

## Dua jenis pool

| Aspek | User Pool | Identity Pool |
|---|---|---|
| Tujuan | user registry + auth | issue AWS credential |
| Output | JWT (Id/Access/Refresh token) | temporary IAM credential |
| Storage user | iya | tidak (refer ke source identity) |
| Source identity | sendiri | User Pool, Google, Facebook, SAML, OIDC |
| Pakai untuk | authorize API kamu | client mobile akses S3/DynamoDB langsung |

Sering pakai dua-duanya: User Pool sebagai source, Identity Pool federate ke AWS credential.

## Pricing mental model

**User Pool**:
- 10.000 MAU (Monthly Active User) gratis permanen.
- Setelah itu: $0.0055 per MAU (sliding scale, lebih murah di volume tinggi).

**MFA via SMS**: $0.06 per SMS (mahal). Pakai TOTP/authenticator app sebagai default gratis.

**Identity Pool**: gratis (cuma cost AWS resource yang di-akses pakai credential issued).

**Advanced security features** (compromise credential detection, adaptive auth): $0.05 per MAU. Worth untuk produksi serius.

Untuk app 5000 MAU: **$0/bulan** Cognito (di bawah free tier). Untuk 100k MAU: ~$385/bulan.

## Local emulator

**Floci status**: ✅ full (Floci-exclusive vs LocalStack Free)

Cognito di Floci jalan beneran (signup, confirm, signin, JWT issuance). Bedanya: email verification tidak benar-benar kirim email. Pakai `admin-confirm-sign-up` untuk bypass.

Fallback kalau tanpa Floci:
- **cognito-local**: npm package, Cognito-compatible API.

## Hello-world

```bash
# User Pool
POOL_ID=$(awsl cognito-idp create-user-pool \
  --pool-name demo \
  --policies 'PasswordPolicy={MinimumLength=8,RequireUppercase=true,RequireNumbers=true}' \
  --username-attributes email \
  --auto-verified-attributes email \
  --query 'UserPool.Id' --output text)

# App Client (untuk frontend, tidak generate secret)
CLIENT_ID=$(awsl cognito-idp create-user-pool-client \
  --user-pool-id $POOL_ID --client-name web \
  --no-generate-secret \
  --explicit-auth-flows ALLOW_USER_PASSWORD_AUTH ALLOW_REFRESH_TOKEN_AUTH \
  --query 'UserPoolClient.ClientId' --output text)

# Signup
awsl cognito-idp sign-up \
  --client-id $CLIENT_ID \
  --username alice@example.com \
  --password 'Passw0rd!' \
  --user-attributes Name=email,Value=alice@example.com

# Confirm (di Floci, force confirm; di AWS asli, alice klik link di email)
awsl cognito-idp admin-confirm-sign-up \
  --user-pool-id $POOL_ID --username alice@example.com

# Signin
awsl cognito-idp initiate-auth \
  --auth-flow USER_PASSWORD_AUTH \
  --client-id $CLIENT_ID \
  --auth-parameters USERNAME=alice@example.com,PASSWORD='Passw0rd!'
```

Output signin: 3 JWT (Id, Access, Refresh).

## Gotcha

- **IdToken vs AccessToken**: untuk authorize API kamu, pakai **IdToken**. AccessToken cuma untuk panggil Cognito API (mis. ganti password). Confused ini bikin auth error mysterious.
- **Password policy locked setelah pool dibuat**: tidak bisa ubah dari 8 ke 12 char minimum. Workaround: bikin pool baru, migrate user.
- **Attribute schema immutable**: tambah custom attribute (`custom:role`, `custom:tier`) setelah pool live butuh bikin pool baru.
- **Email verification susah test lokal**: Floci dan email service tidak terintegrasi. Pakai `admin-confirm-sign-up` di dev.
- **JWT default expiry 1 jam**: client harus refresh sebelum expire pakai RefreshToken. Tanpa refresh, user dipaksa signin ulang.
- **RefreshToken expiry default 30 hari**: bisa di-config sampai 10 tahun. Trade-off security vs UX.
- **Lambda trigger ada banyak hook**: PreSignUp, PostConfirmation, PreAuthentication, dll. Custom auth flow powerful tapi rumit. Test di staging dulu.
- **Hosted UI cuma di AWS asli**: Cognito bundled login page (`https://your-domain.auth.region.amazoncognito.com`). Di Floci tidak ada. Untuk dev lokal, bangun UI sendiri yang panggil API.
- **MFA SMS mahal dan tidak reliable di Indonesia**: prefer TOTP (Google Authenticator, Authy). Setup SMS butuh AWS Pinpoint plus number provisioning.
- **OIDC discovery URL untuk JWT validation**: `https://cognito-idp.<region>.amazonaws.com/<pool-id>/.well-known/openid-configuration`. Library JWT validation (jose, jsonwebtoken+jwks-rsa) butuh ini.
- **App Client secret untuk public client**: jangan generate secret untuk SPA/mobile (`--no-generate-secret`). Secret di public client tidak secret.
