# Service Reference

Halaman deep-dive per AWS service. Setiap halaman pakai template sama: TL;DR, kapan pakai, kapan jangan, pricing model, local emulator, hello-world, gotcha, cross-provider.

Service di-link dari [Use-Case Journey](/id/journeys) yang relevan. Mulai dari journey kalau kamu baru, atau langsung ke service kalau cari detail spesifik.

## Compute

- [Lambda](/id/services/lambda), serverless function
- [ECS](/id/services/ecs), container orchestrator (Fargate atau EC2 launch)
- [EKS](/id/services/eks), managed Kubernetes
- [ECR](/id/services/ecr), Docker registry private

## Storage

- [S3](/id/services/s3), object storage

## Database

- [DynamoDB](/id/services/dynamodb), NoSQL key-value managed
- [RDS](/id/services/rds), managed Postgres / MySQL / MariaDB / Oracle / SQL Server

## API & networking

- [API Gateway](/id/services/apigateway), managed HTTP/REST API + WebSocket
- [ALB](/id/services/alb), Application Load Balancer (layer 7)
- [CloudFront](/id/services/cloudfront), CDN global
- [Route53](/id/services/route53), managed DNS

## Identity & certificate

- [Cognito](/id/services/cognito), user authentication
- [ACM](/id/services/acm), SSL/TLS certificate gratis

## Messaging & orchestration

- [SQS](/id/services/sqs), managed queue
- [SNS](/id/services/sns), pub/sub fanout
- [EventBridge](/id/services/eventbridge), event bus dengan routing rule
- [Step Functions](/id/services/stepfunctions), state machine workflow

## Streaming & analytics

- [Kinesis](/id/services/kinesis), real-time data streaming
- [Data Firehose](/id/services/firehose), batched delivery ke S3 / OpenSearch / Redshift
- [Glue](/id/services/glue), ETL + Data Catalog
- [Athena](/id/services/athena), serverless SQL query untuk data S3

## Observability

- [CloudWatch](/id/services/cloudwatch), metrics + logs + alarm + dashboard
- [X-Ray](/id/services/xray), distributed tracing
- [OpenSearch](/id/services/opensearch), search + log analytics + vector search

> Halaman lain (KMS, Secrets Manager, CloudTrail, GuardDuty, Bedrock, SageMaker) menyusul.
