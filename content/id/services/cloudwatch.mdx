# CloudWatch

**TL;DR**: Observability platform AWS. Metrics, Logs, Alarms, Dashboard, Events (Scheduler), Synthetics, ServiceLens. Tightly integrated ke semua service AWS, otomatis emit metric baseline tanpa setup.

## Analogi

Speedometer + dashboard + alarm + recorder mobil. Built-in di setiap service AWS. Kamu cuma decide alarm dan log retention.

## Kapan pakai

- ✅ Metric standard service AWS (Lambda Duration, RDS CPUUtilization, ALB RequestCount).
- ✅ Log aggregation dari Lambda, ECS, EKS, custom app.
- ✅ Alarm yang trigger SNS/Lambda saat threshold terlampaui.
- ✅ Dashboard untuk monitoring real-time (refresh 1 menit).
- ✅ Synthetic monitoring (canary yang test endpoint berkala).
- ✅ Anomaly detection (ML-based, deteksi spike abnormal).
- ✅ Logs Insights untuk query structured log dengan syntax SQL-like.

## Kapan jangan

- ❌ APM deep (auto-instrument call stack). Pakai Datadog, New Relic, Dynatrace.
- ❌ Full-text search di log volume tinggi. Pakai OpenSearch.
- ❌ Custom dashboard cantik dengan template. Pakai Grafana dengan CloudWatch datasource.
- ❌ Log retention bertahun-tahun cheap. CloudWatch storage mahal jangka panjang, archive ke S3.

## Komponen utama

| Komponen | Fungsi |
|---|---|
| **Metrics** | time-series numeric, default 1-min resolution |
| **Logs** | structured/unstructured text dari service AWS atau app custom |
| **Alarms** | trigger action saat metric crossing threshold |
| **Dashboards** | widget grafik metric |
| **Events / EventBridge** | scheduler + event routing (sekarang merged ke EventBridge) |
| **Synthetics** | scheduled canary script (Selenium/Puppeteer) yang test endpoint |
| **ServiceLens** | service map dengan metric overlay (gabungan dengan X-Ray) |
| **Container Insights** | metric + log khusus ECS/EKS |
| **Lambda Insights** | metric + log khusus Lambda |

## Pricing mental model

| Komponen | Harga (us-east-1) |
|---|---|
| Standard metric (1-min) | gratis untuk service AWS bawaan |
| Custom metric | $0.30/metric/bulan (10 metric gratis) |
| High-resolution metric (1-detik) | mahal, $0.30/metric/bulan + per metric data point |
| Log ingestion | $0.50/GB |
| Log storage | $0.03/GB/bulan |
| Log Insights query | $0.005/GB scanned |
| Alarm | $0.10/bulan per alarm (10 gratis) |
| Dashboard | 3 gratis, $3/dashboard/bulan setelah |
| Synthetics canary | $0.0012 per canary run |
| Anomaly detection | $0.30/alarm/bulan |

Untuk Lambda 1M invocation/bulan + structured log 5 GB: ~$3-5/bulan.

## Local emulator

**Floci status**: ✅ full (Logs + Metrics + Alarm)

```bash
# Log group
awsl logs create-log-group --log-group-name /aws/lambda/my-fn
awsl logs put-retention-policy \
  --log-group-name /aws/lambda/my-fn --retention-in-days 7

# Metric
awsl cloudwatch put-metric-data \
  --namespace MyApp \
  --metric-name OrderCount --value 1

# Alarm
awsl cloudwatch put-metric-alarm \
  --alarm-name high-errors \
  --metric-name Errors --namespace AWS/Lambda \
  --statistic Sum --period 60 \
  --threshold 5 --evaluation-periods 2 \
  --comparison-operator GreaterThanThreshold
```

## Hello-world

### EMF custom metric (gratis, via log)

Tulis log dengan format khusus, CloudWatch auto-ekstrak jadi metric. Tidak butuh `PutMetricData` API call.

```js
console.log(JSON.stringify({
  _aws: {
    Timestamp: Date.now(),
    CloudWatchMetrics: [{
      Namespace: 'MyApp',
      Dimensions: [['environment']],
      Metrics: [{ Name: 'OrderCount', Unit: 'Count' }]
    }]
  },
  environment: 'prod',
  OrderCount: 1
}))
```

### Logs Insights query

```sql
fields @timestamp, requestId, message, level
| filter level = "error"
| stats count() by bin(5m)
| sort @timestamp desc
| limit 100
```

### Dashboard widget

```bash
awsl cloudwatch put-dashboard \
  --dashboard-name app-overview \
  --dashboard-body '{
    "widgets": [{
      "type": "metric",
      "properties": {
        "metrics": [["AWS/Lambda", "Invocations", "FunctionName", "my-fn"]],
        "period": 60,
        "stat": "Sum",
        "title": "Lambda Invocations"
      }
    }]
  }'
```

## Gotcha

- **Log retention default infinite**: cost storage naik diam-diam. Set retention 7-30 hari (atau 90 hari compliance).
- **Custom metric mahal**: $0.30/metric/bulan. Pakai EMF (gratis) instead of `PutMetricData` untuk hemat.
- **Alarm INSUFFICIENT_DATA state**: untuk metric berbasis count (Errors), set `--treat-missing-data notBreaching` supaya alarm tidak fire palsu saat traffic kosong.
- **Metric latency 1-2 menit**: tidak real-time. Untuk real-time dashboard, pakai high-resolution metric (mahal) atau EMF dengan 1-detik resolution.
- **Logs Insights scan cost**: query yang scan banyak data = mahal. Filter dengan time range dan field index.
- **Dashboard cross-region tidak built-in**: dashboard region-scoped. Untuk multi-region view, pakai cross-region observability (setup monitoring account).
- **Log group bukan stream**: log group adalah container. Log stream sub-divisi (biasanya per Lambda instance). API tail log group, bukan stream.
- **Subscription filter ke Lambda/Kinesis/Firehose**: stream log real-time ke destination. Cost tambahan per GB streaming.
- **Alarm state change ke EventBridge**: integrate alarm state change ke EventBridge rule untuk routing (Slack notification, ticket creation).
- **Detailed monitoring vs basic**: detailed = 1-min metric untuk EC2 (basic = 5-min). $2.10 per instance/bulan tambahan. Worth untuk produksi.
